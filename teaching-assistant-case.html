同一套能力，适配不同行业

教师助手只是其中一个场景。底层技术可以迁移到任何数据驱动的业务。
点击卡片查看对应的后端技术能力。

🍽️

餐饮 / 零售

"最近一周哪些菜品销量下滑？"
"会员消费频次下降的客户有哪些？"
AI 自动分析营业数据，给出营销建议。

查看对应能力
  • 数据查询自然语言转结构化查询，自动关联订单、会员、库存多张数据表
  • 趋势分析时间序列聚合 + 同比环比计算，识别销量/客单价异常波动
  • 任务调度异步报表生成 + 实时进度推送，大数据量不卡顿
  • 消息触达根据分析结论自动生成营销文案，一键推送给目标客群
🏥

诊所 / 健康

"哪些患者复诊周期异常？"
"本月预约取消率最高的时段是？"
从预约记录中自动识别风险患者。

查看对应能力
  • 风险识别多维度数据交叉验证（预约间隔 + 就诊频次 + 用药记录）
  • 自然语言医生口头描述直接解析为结构化病历标签，无需手动填写表单
  • 权限管理多角色访问控制（医生/护士/前台），数据隔离 + 操作审计
  • 提醒引擎基于规则的自动提醒 + 基于 AI 的异常预警双轨并行
🏭

小型工厂 / 贸易

"哪些供应商交货延迟超过 3 次？"
"库存周转最慢的品类是？"
把进销存数据变成可执行的洞察。

查看对应能力
  • 数据导入Excel/CSV 智能识别 + 字段自动映射，历史数据一键迁移
  • 库存分析ABC 分类 + 周转率计算 + 安全库存预警，自动生成补货建议
  • 供应商评估交货准时率、质量合格率、价格波动多指标加权评分模型
  • 文档解析合同/单据扫描件 OCR + LLM 结构化提取，告别手工录入
📚

教育 / 培训

"最近成绩波动大的学生有哪些？"
"哪个知识点的错题率最高？"
自然语言查询成绩、生成沟通建议。

查看对应能力
  • Agent 引擎多步推理规划 → 工具调用 → 结果合成，不是简单问答
  • 成绩分析分层统计 + 趋势追踪 + 进退步排名，班级/个人多维对比
  • 知识图谱题目-知识点关联树 + 错题归因，定位薄弱知识环节
  • 智能生成基于数据上下文自动生成评语、沟通草稿、表现记录
